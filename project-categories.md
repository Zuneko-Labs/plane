## Handover Approval Gate — mapping per category

Only a project **Admin** can move a work item into the **Approved** state, and only from **Pending Approval**. The gate is **ON** for every project.

- **Approved** = the last step of each category
- **Pending Approval** = a state named **Closed**, placed right before the last step (added as a new state where it doesn't exist yet)
- **Sent Back** = the step right before Closed (the one an Admin sends a work item back to, with a comment)

| Category | Pending Approval | Approved | Sent Back |
|---|---|---|---|
| 1. Public Notice | Closed *(new)* | Publish/Close | Draft verified (?) |
| 2. Legal Notice / Notice Reply | Closed *(new)* | Post/Close | Draft verified (?) |
| 3. Document Review | Closed *(new)* | Completed | Pending for Payment (?) |
| 4. MOU / Affidavit / Agreements | Closed *(new)* | Handedover | Draft verified and Notarised (?) |
| 5. All remaining | Closed *(exists)* | Excel entry and Handover | Xerox and Binding |
| 6. Search Report | Closed *(new)* | Handover & Billing | Search Report Finalisation (?) |

> In categories 1, 2 and 4, **"Sent for Approval"** stays an ordinary work step. The gate uses **Closed** as its Pending Approval step.
